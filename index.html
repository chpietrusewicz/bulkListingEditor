Getting Started

Welcome to the Bulk Listing Editor! This tool helps you create and manage multiple product listings efficiently.

How to Use

  1. Upload CSV: Start by uploading a CSV file with your product data on the List screen.
  2. Fill Details: Complete the required fields (Title, Category, Description, Price, Quantity).
  3. Edit Listings: Review and modify your listings in the editor view.
  4. Save Batch: Click "Save and Quit" to save your current batch for later.
  5. Export: When ready, click "Export" to generate your final listing files.

Navigation

  • Home: Return to the welcome screen
  • List: Upload and configure new listings
  • Images: View all saved batches
  • Analytics: (Coming soon) View listing statistics
  • Help: Access this help guide

Tips

  • Make sure your CSV file is properly formatted before uploading
  • Fill in all required fields to avoid export errors
  • Save your work regularly using "Save and Quit"
  • You can edit saved batches by clicking on them in the Batches screen
  • The export process may take a few moments depending on batch size
